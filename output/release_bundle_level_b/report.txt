10. ОГРАНИЧЕНИЯ
   - Размер выборки: полный пакет -- 5 событий; малые группы (см. sample_warning) не позволяют уверенных выводов.
   - Вероятности -- эмпирические доли в прошлой выборке, не прогноз; доверительные интервалы здесь не строились.
   - Реакция измеряется от закрытия T-1m: ожидание рынка и движение до публикации не учитываются, а движение за первую минуту включает также спред/проскальзывание, отражённое в mid лишь частично.
   - События с пересекающимися окнами (<120 мин между публикациями): 0 -- их реакции не независимы.
   - Не разделялись сюрприз (факт vs прогноз), направление отчёта, режим волатильности и другие факторы; этап B описывает безусловную реакцию по составу пакета.
   - UP/DOWN/ZERO -- по точному знаку изменения; ZERO редок, поэтому смотрите пороговую (flat) чувствительность.
   - Диагностика дублей/некорректных цен/spread выполнена только по свечам в окнах событий (не по всему архиву).
   - Определение файлов по диапазону дат делается по первой/последней строке файла (имя файла не используется); для неотсортированных CSV используйте --no-prefilter.
   - Праздники не определяются по календарю: они видны как отсутствие свечей (NO_QUOTES_IN_EVENT_WINDOW / MISSING_BASELINE); выходные помечены по дню недели UTC.
   - Множественные сравнения: групп×горизонтов много, отдельные «значимые» p-value без поправки ничего не доказывают.
